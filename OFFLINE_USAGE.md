# Uso della versione offline

## File pronto all'uso
- `supporto_rendicontazione_offline.html`

## Come aprirlo senza internet
1. Copia questo file su qualunque computer.
2. Fai doppio clic sul file `supporto_rendicontazione_offline.html`.
3. In alternativa, aprilo con un link locale del tipo:
   - `file:///C:/percorso/supporto_rendicontazione_offline.html` su Windows
   - `file:///Users/nome/percorso/supporto_rendicontazione_offline.html` su macOS
   - `file:///home/nome/percorso/supporto_rendicontazione_offline.html` su Linux

- Salvataggio locale nel browser
